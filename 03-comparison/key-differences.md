## 상세 비교표

### 기본 특성

| 항목 | EKS Hybrid Nodes | EKS Anywhere |
|------|------------------|--------------|
| **출시일** | 2024년 12월 | 2021년 9월 |
| **Control Plane 위치** | AWS Cloud | 온프레미스 |
| **기반 배포판** | Amazon EKS | EKS Distro (EKS-D) |
| **K8s 버전** | EKS 버전과 동일 | EKS-D 버전 |
| **AWS 연결** | 필수 | 선택 |
| **Air-gapped 지원** | ❌ | ✅ |

## 지원 인프라 상세

### EKS Hybrid Nodes 지원 환경

```
지원 OS:
├── Amazon Linux 2023
├── Ubuntu 20.04, 22.04
└── RHEL 8, 9

요구 사항:
├── x86_64 또는 ARM64
├── 최소 1 vCPU, 1GB RAM
├── containerd 런타임
├── AWS SSM Agent
└── 네트워크 연결 (AWS endpoint 접근 가능)
```

### EKS Anywhere 지원 환경

```
인프라 프로바이더:
├── VMware vSphere 7.0+
├── Bare Metal (Tinkerbell)
├── Nutanix
├── Apache CloudStack
└── AWS Snow

지원 OS:
├── Bottlerocket (권장)
├── Ubuntu 20.04, 22.04
└── RHEL 8 (일부 프로바이더)

구성 옵션:
├── Standalone (단일 클러스터)
└── Management + Workload (멀티 클러스터)
```

## 선택 시 고려사항

### EKS Hybrid Nodes 선택 시

> ✅ **완료**
>
> **장점**
> - Control Plane 운영 부담 제로
> - AWS 서비스 네이티브 통합
> - 익숙한 EKS 경험
> - AWS Support 활용 가능

> ⚠️ **주의**
>
> **주의점**
> - AWS 연결 필수 (단절 시 제약)
> - 네트워크 레이턴시 고려 필요
> - vCPU 기반 추가 비용

### EKS Anywhere 선택 시

> ✅ **완료**
>
> **장점**
> - 완전한 오프라인 운영 가능
> - Control Plane 완전 통제
> - 기본 비용 없음
> - VMware 환경 최적화

> ⚠️ **주의**
>
> **주의점**
> - Control Plane 운영 책임
> - 직접 HA 구성 필요
> - 업그레이드 복잡도
