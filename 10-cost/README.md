# 비용 분석

> "온프레미스가 클라우드보다 정말 저렴한가요?"

"온프레미스 = 저렴" 또는 "클라우드 = 비쌈"이라는 단순한 공식은 없습니다. 상황에 따라 다릅니다.

## TCO 구성 요소

```
┌─────────────────────────────────────────────────────────────────┐
│                Total Cost of Ownership (TCO)                    │
│                                                                 │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  직접 비용                                               │  │
│   │  ├── 하드웨어 (서버, 스토리지, 네트워크)               │  │
│   │  ├── 소프트웨어 라이선스                                │  │
│   │  ├── 클라우드 서비스 요금                               │  │
│   │  └── 전력, 냉각, 공간                                   │  │
│   └─────────────────────────────────────────────────────────┘  │
│                                                                 │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  간접 비용                                               │  │
│   │  ├── 운영 인력                                          │  │
│   │  ├── 교육                                               │  │
│   │  ├── 다운타임 비용                                      │  │
│   │  └── 보안 사고 비용                                     │  │
│   └─────────────────────────────────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 솔루션별 비용

|----------|------------------|--------------|

| **네트워크** | VPN/DX 비용 | $0 |
