# EKS Hybrid Nodes 비용

## 비용 구조

```
┌─────────────────────────────────────────────────────────────────┐
│                EKS Hybrid Nodes 비용                            │
│                                                                 │
│   1. EKS Control Plane: $0.10/시간                             │
│      └── 약 $73/월                                             │
│                                                                 │
│   2. Hybrid Node: vCPU당 $0.01/시간                            │
│      └── 4 vCPU 노드 10대 = 40 × $0.01 × 730 = $292/월        │
│                                                                 │
│   3. 네트워크:                                                  │
│      ├── Site-to-Site VPN: $0.05/시간 + 데이터 전송           │
│      └── Direct Connect: 포트 비용 + 데이터 전송              │
│                                                                 │
│   4. 데이터 전송:                                               │
│      └── AWS → On-Prem: $0.09/GB (첫 10TB)                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 예시 계산

```
10대 Hybrid Node (각 4 vCPU) 월간 비용:

┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   EKS Control Plane           $73                              │
│   Hybrid Nodes (40 vCPU)      $292                             │
│   VPN                         $37 (~)                          │
│   데이터 전송 (100GB)         $9                               │
│   ─────────────────────────────────────────                    │
│   총계                        ~$410/월                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 비용 최적화 팁

```
✅ 필요한 vCPU만 노드에 할당
✅ 사용하지 않는 노드는 클러스터에서 제거
✅ ARM 기반 서버 활용 검토 (동일 비용)
✅ Reserved Instance 계약 검토 (Direct Connect)
```
