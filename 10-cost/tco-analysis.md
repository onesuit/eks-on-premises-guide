# TCO 분석 및 비교

## 규모별 비용 비교

```
┌─────────────────────────────────────────────────────────────────┐
│                 규모별 월간 비용 비교                           │
│                                                                 │
│   소규모 (10 노드, 40 vCPU):                                   │
│   ├── EKS Hybrid Nodes: ~$410/월 + 운영인력 적음              │
│   └── EKS Anywhere: ~$5,000/월 (운영인력 포함)                │
│       → Hybrid Nodes 유리                                      │
│                                                                 │
│   중규모 (50 노드, 200 vCPU):                                  │
│   ├── EKS Hybrid Nodes: ~$1,500/월 + 운영인력 중간            │
│   └── EKS Anywhere: ~$6,000/월 (운영인력 포함)                │
│       → 비슷하거나 Hybrid Nodes 유리                           │
│                                                                 │
│   대규모 (200 노드, 800 vCPU):                                 │
│   ├── EKS Hybrid Nodes: ~$6,000/월 + 운영인력                 │
│   └── EKS Anywhere: ~$8,000/월 (운영인력 포함)                │
│       → 비슷, 운영 역량에 따라 다름                            │
│                                                                 │
│   초대규모 (500+ 노드):                                        │
│   └── EKS Anywhere + Enterprise Support 고려                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 결정 포인트

```
EKS Hybrid Nodes 선택:
├── 운영 인력이 제한적
├── AWS 서비스 통합 필요
├── 빠른 도입 필요
└── Control Plane 관리 부담 줄이고 싶음

EKS Anywhere 선택:
├── 충분한 운영 역량 보유
├── 대규모 (vCPU 비용 부담)
├── Air-gapped 환경
└── 완전한 통제권 필요
```

## 숨겨진 비용 고려

```
자주 잊는 비용:
├── 교육 비용 (K8s, EKS 교육)
├── 다운타임 비용 (장애 시 비즈니스 영향)
├── 기회 비용 (운영팀이 인프라에 매달림)
└── 보안 사고 비용 (미숙한 운영으로 인한 사고)
```
