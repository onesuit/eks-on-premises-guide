# 연결 방식: VPN vs Direct Connect

> "AWS랑 어떻게 연결하는 게 좋을까요?"

EKS Hybrid Nodes는 AWS Control Plane과 안정적인 연결이 필요합니다.

## 연결 방식 비교

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   Site-to-Site VPN                   AWS Direct Connect         │
│   ┌─────────────────────┐           ┌─────────────────────┐    │
│   │                     │           │                     │    │
│   │  인터넷 기반        │           │  전용선 기반        │    │
│   │                     │           │                     │    │
│   │  • 빠른 설정        │           │  • 일관된 성능      │    │
│   │  • 저렴한 비용      │           │  • 낮은 레이턴시    │    │
│   │  • 성능 변동        │           │  • 높은 비용        │    │
│   │                     │           │  • 설치 시간 필요   │    │
│   │                     │           │                     │    │
│   └─────────────────────┘           └─────────────────────┘    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

| 항목 | Site-to-Site VPN | Direct Connect |
|------|-----------------|----------------|
| **설정 시간** | 몇 시간 | 몇 주~몇 달 |
| **대역폭** | ~1.25 Gbps | 1~100 Gbps |
| **레이턴시** | 변동 | 일관적, 낮음 |
| **비용** | 낮음 | 높음 |
| **안정성** | 인터넷 의존 | 매우 높음 |
| **암호화** | 기본 제공 | 선택 (MACsec) |

## VPN 설정

```
┌─────────────────────────────────────────────────────────────────┐
│                        VPN 구성                                 │

│   │                 │              │                 │         │

```

```
│                                                                 │

│   │            │        │            │         │            │ │
│   │  AWS       │◄──────►│  Coloca-   │◄───────►│  Customer  │ │
│   │  Region    │  AWS   │  tion      │  Cross  │  Router    │ │
│   │            │  link  │  Provider  │  Connect│            │ │
│   │            │        │            │         │            │ │

```

## 권장 구성

### 개발/테스트 환경

```
VPN 단독:
├── 비용 최소화
├── 빠른 설정
└── 성능 변동 허용
```

### 프로덕션 환경

```
Direct Connect + VPN 백업:
├── Primary: Direct Connect
├── Backup: Site-to-Site VPN
└── 장애 시 자동 전환
```
