# 네트워크

> "온프레미스 Kubernetes 네트워킹이 왜 복잡한 거예요?"

클라우드에서는 AWS VPC가 많은 것을 자동으로 처리해주지만, 온프레미스에서는 직접 구성해야 할 것들이 많습니다.

## 온프레미스 네트워크 구성 요소

```
┌─────────────────────────────────────────────────────────────────┐
│                 Kubernetes 네트워크 스택                        │
│                                                                 │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  Layer 7: Ingress Controller (nginx, Traefik)           │  │
│   └─────────────────────────────────────────────────────────┘  │
│                              │                                  │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  Layer 4: Service (ClusterIP, NodePort, LoadBalancer)   │  │
│   └─────────────────────────────────────────────────────────┘  │
│                              │                                  │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  CNI: Pod 네트워킹 (Cilium, Calico)                     │  │
│   └─────────────────────────────────────────────────────────┘  │
│                              │                                  │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  물리 네트워크: 스위치, 라우터, 방화벽                   │  │
│   └─────────────────────────────────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## EKS Hybrid Nodes vs EKS Anywhere 네트워크

| 구성 요소 | EKS Hybrid Nodes | EKS Anywhere |
|----------|------------------|--------------|
| **CNI** | VPC CNI(Remote) 또는 Cilium | Cilium |
| **AWS 연결** | VPN/Direct Connect 필수 | 선택 |
| **Pod CIDR** | VPC와 겹치면 안 됨 | 자유 설정 |
| **LoadBalancer** | AWS ELB 또는 MetalLB | MetalLB |
| **DNS** | Route 53 통합 가능 | CoreDNS |
