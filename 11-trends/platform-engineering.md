# Platform Engineering

> "개발자가 Kubernetes를 몰라도 되게 할 수 없나요?"

Platform Engineering은 Kubernetes의 복잡성을 추상화하여 개발자 경험을 향상시키는 접근법입니다.

## Internal Developer Platform (IDP)

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   개발자                                                        │
│      │                                                          │
│      │  "웹 앱 배포해줘"                                       │
│      ▼                                                          │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │             Internal Developer Platform                  │  │
│   │                                                          │  │
│   │   ┌─────────────────────────────────────────────────┐   │  │
│   │   │  Self-Service Portal                            │   │  │
│   │   │  ├── 앱 템플릿 선택                            │   │  │
│   │   │  ├── 환경 선택 (dev/prod)                      │   │  │
│   │   │  └── 배포 버튼 클릭                            │   │  │
│   │   └─────────────────────────────────────────────────┘   │  │
│   │                         │                                │  │
│   │                         ▼                                │  │
│   │   ┌─────────────────────────────────────────────────┐   │  │
│   │   │  Platform Automation                            │   │  │
│   │   │  ├── YAML 자동 생성                            │   │  │
│   │   │  ├── GitOps 파이프라인                         │   │  │
│   │   │  └── 보안 정책 적용                            │   │  │
│   │   └─────────────────────────────────────────────────┘   │  │
│   │                                                          │  │
│   └─────────────────────────────────────────────────────────┘  │
│                         │                                      │
│                         ▼                                      │
│   ┌─────────────────────────────────────────────────────────┐ │
│   │               Kubernetes Cluster                         │ │
│   │  (개발자는 이 복잡성을 모름)                            │ │
│   └─────────────────────────────────────────────────────────┘ │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 주요 도구

| 도구 | 설명 |
|------|------|
| **Backstage** | Spotify의 오픈소스 IDP 프레임워크 |
| **Port** | 상용 IDP 솔루션 |
| **Kratix** | Platform-as-a-Product |
| **Crossplane** | 인프라 추상화 |

## 온프레미스에서의 Platform Engineering

```
EKS Anywhere + Backstage:
├── 개발자는 Backstage UI만 사용
├── Platform 팀이 K8s 관리
├── 템플릿으로 표준화
└── 셀프서비스로 병목 제거
```
