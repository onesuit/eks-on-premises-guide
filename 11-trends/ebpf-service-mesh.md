# eBPF와 Service Mesh

> "Sidecar 없는 Service Mesh가 가능하다고요?"

eBPF 기반 도구들이 Kubernetes 네트워킹과 관측성을 혁신하고 있습니다.

## eBPF란?

```
┌─────────────────────────────────────────────────────────────────┐
│                        eBPF                                     │
│                                                                 │
│   기존 방식 (User Space):                                      │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  Application → Sidecar → iptables → 커널               │  │
│   │                                                          │  │
│   │  오버헤드: 높음                                         │  │
│   └─────────────────────────────────────────────────────────┘  │
│                                                                 │
│   eBPF 방식 (Kernel Space):                                    │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  Application → 커널 (eBPF 프로그램)                     │  │
│   │                                                          │  │
│   │  오버헤드: 매우 낮음                                    │  │
│   └─────────────────────────────────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## Cilium Service Mesh

```
┌─────────────────────────────────────────────────────────────────┐
│             Cilium Service Mesh (Sidecar-free)                  │
│                                                                 │
│   기존 Istio:                                                   │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  Pod                                                     │  │
│   │  ┌─────────────┐  ┌─────────────┐                       │  │
│   │  │    App      │  │   Envoy     │ ← Sidecar            │  │
│   │  │  Container  │  │   Sidecar   │   (리소스 소비)      │  │
│   │  └─────────────┘  └─────────────┘                       │  │
│   └─────────────────────────────────────────────────────────┘  │
│                                                                 │
│   Cilium:                                                       │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │  Pod                                                     │  │
│   │  ┌─────────────┐                                        │  │
│   │  │    App      │   ← Sidecar 없음!                      │  │
│   │  │  Container  │                                        │  │
│   │  └─────────────┘                                        │  │
│   │         │                                                │  │
│   │         ▼                                                │  │
│   │  ┌─────────────────────────────────────────────────┐    │  │
│   │  │  eBPF (커널 레벨에서 처리)                       │    │  │
│   │  └─────────────────────────────────────────────────┘    │  │
│   └─────────────────────────────────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## Tetragon (런타임 보안)

```yaml
# Tetragon: 런타임 보안 정책
apiVersion: cilium.io/v1alpha1
kind: TracingPolicy
metadata:
  name: detect-shell
spec:
  kprobes:
  - call: "sys_execve"
    selectors:
    - matchArgs:
      - index: 0
        operator: "Equal"
        values:
        - "/bin/bash"
        - "/bin/sh"
```
