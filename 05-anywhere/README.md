# EKS Anywhere

> "Control Plane부터 Worker Node까지, 전부 우리 데이터센터에서 운영할 수 있다고요?"

네, 맞습니다. EKS Anywhere는 2021년에 출시된 AWS의 온프레미스 Kubernetes 솔루션으로, **완전히 독립적인** 클러스터를 온프레미스에서 운영할 수 있게 해줍니다.

## EKS Anywhere란?

한 문장으로 정리하면:

> **EKS의 도구와 경험을 온프레미스에서 사용하여, Control Plane과 Worker Node 모두를 직접 운영하는 것**

## 왜 EKS Anywhere인가?

### 다른 옵션들과의 비교

**옵션 1: 직접 K8s 구축 (kubeadm)**

```
❌ 모든 것을 처음부터 구성
❌ 업그레이드 복잡
❌ 지원 없음
❌ 일관성 없는 경험
```

**옵션 2: Rancher, OpenShift 등**

```
⚠️ 벤더 종속
⚠️ 별도의 에코시스템
⚠️ AWS와 다른 경험
```

**옵션 3: EKS Anywhere**

```
✅ AWS가 검증한 구성 (EKS Distro)
✅ AWS와 유사한 경험
✅ 선택적 AWS 지원
✅ 오픈소스 기반
✅ 인터넷 연결 없이도 운영 가능
```

## 핵심 가치 제안

### 1. 완전한 독립성

```
인터넷 연결 상태와 무관하게 모든 기능 사용 가능:

✅ 새 Pod 배포
✅ kubectl 명령
✅ 스케일링
✅ 업그레이드
✅ 모니터링 (로컬)
✅ 로깅 (로컬)
```

### 2. EKS Distro 기반

EKS Distro(EKS-D)는 AWS EKS에서 사용하는 것과 동일한 Kubernetes 배포판입니다.

```
AWS EKS                          EKS Anywhere
┌─────────────────────┐          ┌─────────────────────┐
│                     │          │                     │
│   EKS Control Plane │          │   EKS Distro        │
│   (AWS Managed)     │   같은   │   (Self Managed)    │
│                     │   코드   │                     │
│   • Kubernetes      │◄────────►│   • Kubernetes      │
│   • etcd            │          │   • etcd            │
│   • CoreDNS         │          │   • CoreDNS         │
│   • CNI             │          │   • CNI (Cilium)    │
│                     │          │                     │
└─────────────────────┘          └─────────────────────┘
```

### 3. GitOps 기본 내장

Flux가 기본으로 포함되어 있어 GitOps 방식의 운영이 쉽습니다.

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   Git Repository                      EKS Anywhere Cluster      │
│   ┌──────────────┐                    ┌──────────────────┐     │
│   │              │     Flux           │                  │     │
│   │  manifests/  │───────────────────►│    Apply         │     │
│   │  ├── apps/   │     자동 동기화    │    Changes       │     │
│   │  └── infra/  │                    │                  │     │
│   │              │                    │                  │     │
│   └──────────────┘                    └──────────────────┘     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 지원 인프라

### 인프라 프로바이더

| 프로바이더 | 설명 | 적합한 환경 |
|-----------|------|------------|
| **VMware vSphere** | vCenter 통합, VM 자동 프로비저닝 | 기존 VMware 환경 |
| **Bare Metal (Tinkerbell)** | 물리 서버 직접 사용 | 최대 성능 필요 |
| **Nutanix** | Nutanix AHV 통합 | Nutanix 사용 조직 |
| **Apache CloudStack** | CloudStack 통합 | CloudStack 사용 조직 |
| **AWS Snow** | Snow 디바이스에서 실행 | 엣지/원격 환경 |

### 운영체제

```
지원 OS:
├── Bottlerocket (권장)
│   └── 컨테이너 전용 OS, 최소 공격 표면
├── Ubuntu 20.04, 22.04
│   └── 범용, 익숙한 환경
└── RHEL 8 (일부 프로바이더)
    └── 엔터프라이즈 지원 필요 시
```

## EKS Connector로 AWS 연동

완전히 독립적으로 운영하면서도, 선택적으로 AWS 콘솔에서 볼 수 있습니다.

```
┌────────────────────────────────────────────────────────────────────┐
│                                                                    │
│   On-Premises                           AWS Console                │
│   ┌──────────────────────┐              ┌────────────────────┐    │
│   │  EKS Anywhere        │              │                    │    │
│   │  Cluster             │   Connector  │  EKS Console       │    │
│   │                      │─────────────►│  (읽기 전용 뷰)    │    │
│   │  • Full Control      │              │                    │    │
│   │  • Independent       │              │  • 클러스터 상태   │    │
│   │                      │              │  • 노드 목록       │    │
│   └──────────────────────┘              │  • 워크로드 현황   │    │
│                                         │                    │    │
│                                         └────────────────────┘    │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘

제어 방향: On-Premises에서만 (AWS는 보기만)
```
