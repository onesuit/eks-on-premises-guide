## EKS Hybrid Nodes vs EKS Anywhere 운영 비교

| 운영 항목 | EKS Hybrid Nodes | EKS Anywhere |
|----------|------------------|--------------|
| **Control Plane 업그레이드** | AWS 관리 (버튼 클릭) | 직접 수행 |
| **Worker 업그레이드** | 직접 (nodeadm) | 직접 (eksctl) |
| **etcd 백업** | AWS 자동 | 직접 구성 |
| **모니터링** | CloudWatch 통합 | 직접 구성 |
| **로그 수집** | CloudWatch Logs | 직접 구성 |
| **알림** | CloudWatch Alarms | 직접 구성 |
| **장애 복구** | AWS SLA | 직접 대응 |
