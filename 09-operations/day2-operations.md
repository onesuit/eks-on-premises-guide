## 클러스터 상태 확인

```bash
# 노드 상태
kubectl get nodes
kubectl top nodes

# 시스템 Pod
kubectl get pods -n kube-system

# 이벤트
kubectl get events --sort-by='.lastTimestamp'

# 리소스 사용량
kubectl describe nodes | grep -A 5 "Allocated resources"
```
